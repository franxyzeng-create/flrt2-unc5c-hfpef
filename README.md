# Fibroblast FLRT2–UNC5C signalling in human obese HFpEF

Reproducible analysis code for a cross-modal single-nucleus + orthogonal-bulk study of a fibroblast **FLRT2–UNC5C** signal in human heart failure with preserved ejection fraction (HFpEF).

> **Paper:** *Fibroblast FLRT2–UNC5C signalling in human obese HFpEF: a single-nucleus and orthogonal-bulk study.* `<Authors>`. `<Journal>`, `<Year>`. DOI: `<paper DOI>`.
> **Repository:** https://github.com/franxyzeng-create/flrt2-unc5c-hfpef · **Archived (this release):** figshare DOI `10.6084/m9.figshare.32813990`

---

## Overview

We re-analyse public human HFpEF myocardial single-nucleus RNA-seq with CellChat cell–cell communication inference, then triangulate the lead candidates against an orthogonal bulk HFpEF transcriptome. The analysis converges on a single, falsifiable finding: an upregulated fibroblast **FLRT2→UNC5C** autocrine signal in obese HFpEF, anchored cross-modally by the **ligand FLRT2** (the receptor UNC5C is within-modality evidence; bulk-uninformative).

Key design choices encoded in the code:

- **Patient-level (per-donor) testing**, not cell pooling, to avoid pseudoreplication.
- **Two co-primary axes** (absolute `population.size = TRUE`; relative proportion); headline = their intersection.
- **Three-arm ambient-RNA robustness** (raw Cell Ranger / author CellBender / de-novo DecontX).
- **Compartment-specific cross-modal validation** (ligand in sender compartment, receptor in receiver compartment) under a pre-locked 3-tier rule (corroborate / disconfirm / uninformative).
- **BMI de-confounding** (DESeq2 `~ BMI + condition`).
- A fixed seed (`seed.use = 1`, single thread); CellChat steps verified bit-identical on re-execution.

## Data availability (external — NOT in this repository)

Raw data are public and **not redistributed here**; download them to `data/` before running.

| Dataset | Role | Source |
|---|---|---|
| Hahn et al., *Circ Res* 2026 — HFpEF snRNA-seq (48,886 nuclei × 36,601 genes; 19 HFpEF / 24 control) | Discovery | Broad Single Cell Portal, accession **SCP3342** (`HFpEF_snRNAseq.h5ad`; layers `raw_count_cellranger`, `raw_count_cellbender`) |
| Hahn et al., *Circulation* 2021 — RV-septal bulk RNA-seq (41 HFpEF / 30 HFrEF / 24 control) | Orthogonal validation | **Zenodo 4114617** (`DEG_allresultsRVS.csv`, DESeq2 results; `.pef` = HFpEF-vs-control) |
| Kuppe et al. 2022 (Visium) / Kanemaru et al. 2023 (normal heart) | Spatial gate only (exploratory) | Public; used to test FLRT2/UNC5C co-detection — co-detected in <1% of fibroblast spots → spatial co-localisation left open (not a result) |

## Software environment

- **R 4.6.0 / Bioconductor 3.23**, macOS (Apple Silicon, 16 GB).
- **CellChat 2.2.0.9001** (cell–cell communication).
- Core packages: `zellkonverter`, `SingleCellExperiment`, `DESeq2`, `limma`/`edgeR` (voom), `celda` (DecontX), `Matrix`, `dplyr`, `tidyr`; figures: `ggplot2`, `svglite`, `igraph`.
- Full versions/seeds are captured in `sessionInfo()`; **a `renv.lock` is recommended** for exact reproduction (`renv::snapshot()`).

## Reproduction pipeline

Download data to `data/`, then run `scripts/` in numeric order. Stages map to **Methods §2** and produce the files in `results/`:

| Stage (scripts) | Methods | Key output(s) |
|---|---|---|
| Pipeline positive control — `01`, `01b` | §2.3 | `DE_*_pseudobulk.csv` (limma-voom; r = 0.99 vs original) |
| CellChat inference + reproducibility — `02`–`04` | §2.1, §2.4 | `cc_pathway_rank_final.csv`, `rankNet_wilcox_BH.csv`, `cellchat_*_final.rds` |
| Layer identity + de-novo DecontX — `05`–`07b` | §2.2 | de-ambient / DecontX arms |
| Three-arm ambient robustness — `08`–`08a` | §2.5 | `three_arm_robustness.csv` |
| Per-donor pathway testing — `09`–`13` | §2.5 | `perdonor_test_absolute.csv`, `perdonor_test_relative.csv`, `step3_confound_check.csv` |
| Sex sensitivity — `14` | §2.5 | `step3_sex_sensitivity.rds` (female-only + van Elteren) |
| Mechanism layer (LR pairs, sender→receiver) — `15` | §2.4 | `mech_LR_pairs.csv`, `mech_sender_receiver.csv` |
| Cross-modal validation — `16`–`18` | §2.6 | `leg1_hahn2021_bulk_targets.csv`, `leg1b_snRNA_compartment_vs_bulk.csv` |
| Per-donor co-expression — `19`–`20` | §2.7 | `coexpr_per_donor.csv`, `coexpr_per_donor_cellbender.csv` |
| BMI de-confounding — `21` | §2.8 | BMI-adjusted FLRT2 effect |
| Detected-genes confound add-on — `detected_genes_confound_addon.R` | §2.5 | `detected_genes` column in `step3_confound_check.csv` |
| Spatial gate (exploratory) — `spatial_gate_*` | Discussion | FLRT2/UNC5C fibroblast-spot co-detection <1% |
